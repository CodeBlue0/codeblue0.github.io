HackTheBox의 모의해킹 자격증인 **CPTS(Certified Penetration Testing Specialist)**를 준비합니다.
주당 12~15시간씩 공부해서 22주 동안 Academy 경로를 끝내고 시험을 보는 것이 목표입니다.

## CPTS를 고른 이유

- 시험이 10일 동안 실제 기업 네트워크를 침투하고 **상용 수준의 보고서**를 제출하는 방식입니다.
- 웹, 서비스, Active Directory, 피보팅, 권한 상승까지 모의해킹 실무 흐름을 한 경로로 다룹니다.
- 학습 경로(Academy 모듈)가 체계적이라 독학 순서를 정하기 좋습니다.

## 주차별 계획

| 주차 | 기간 | 모듈 |
|---|---|---|
| W1 | 9/22 ~ 9/28 | Penetration Testing Process, Getting Started |
| W2 | 9/29 ~ 10/5 | Network Enumeration with Nmap, Footprinting |
| W3 | 10/6 ~ 10/12 | Information Gathering - Web Edition, Vulnerability Assessment |
| W4 | 10/13 ~ 10/19 | File Transfers, Shells & Payloads, Metasploit |
| W5 | 10/20 ~ 10/26 | Password Attacks |
| W6 | 10/27 ~ 11/2 | Attacking Common Services |
| W7 | 11/3 ~ 11/9 | Pivoting, Tunneling, and Port Forwarding |
| W8–9 | 11/10 ~ 11/23 | Active Directory Enumeration & Attacks |
| W10 | 11/24 ~ 11/30 | Web Proxies, Ffuf, Login Brute Forcing |
| W11 | 12/1 ~ 12/7 | SQL Injection, SQLMap, XSS |
| W12 | 12/8 ~ 12/14 | File Inclusion, File Upload, Command Injection |
| W13 | 12/15 ~ 12/21 | Web Attacks |
| W14–15 | 12/22 ~ 1/4 | Attacking Common Applications |
| W16 | 1/5 ~ 1/11 | Linux Privilege Escalation |
| W17 | 1/12 ~ 1/18 | Windows Privilege Escalation |
| W18 | 1/19 ~ 1/25 | Documentation & Reporting |
| W19–20 | 1/26 ~ 2/8 | Attacking Enterprise Networks (경로 완료) |
| W21–22 | 2/9 ~ 2/22 | 복습, AD 머신 실습, 연습 보고서 1편 |

## 비용

| 항목 | 금액 |
|---|---|
| Student 구독 (약 6개월) | 월 $8~10 |
| 시험 바우처 | $210 |
| 합계 | 약 $270 |

## 기록 방식

모듈을 하나 끝낼 때마다 핵심 개념과 명령어를 Study 카테고리에 정리하고, 주 단위로 진행 상황을 회고하겠습니다.
