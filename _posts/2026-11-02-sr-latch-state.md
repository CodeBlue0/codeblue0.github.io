블로그에 직접 눌러볼 수 있는 회로를 하나 붙였다. NOR 게이트 두 개로 만든 SR 래치다. Set으로 1을 저장하고 Reset으로 지우는 것까지는 간단한데, 두 입력을 같이 켰다가 끄는 경우를 어떻게 표시할지가 남았다.

아래는 브라우저에서 돌아가는 논리 모델이다. 블로그 작성과 인터랙션을 시험하려고 Codex로 만든 예시라 실제 장비에서 측정한 기록은 아니다.

일단 Set을 누른 다음 유지로 바꿔보면 된다. S와 R은 둘 다 0인데 Q는 1로 남는다. 반대로 Reset을 누른 다음 유지로 바꾸면 Q는 0이다.

{% include posts/latch-lab.html %}

같은 입력인데 결과가 다르다. 입력이 00일 때는 직전에 저장된 값을 그대로 쓰기 때문이다. 아래 표에서 ‘이전 값’이라고 적는 부분이 이 동작이다.

| S | R | Q | Q_bar |
| :--: | :--: | :--: | :--: |
| 0 | 0 | 이전 값 | 이전 값 |
| 1 | 0 | 1 | 0 |
| 0 | 1 | 0 | 1 |
| 1 | 1 | 0 | 0 |

회로를 보면 출력이 반대편 게이트의 입력으로 돌아간다. 입력을 꺼도 이 연결이 남아 있어서 상태가 유지된다. 이 글에서 쓰는 건 입력이 1일 때 동작하는 NOR형이다. NAND형 SR 래치는 입력 조건이 다르다.

```text
Q     = NOT (R OR Q_bar)
Q_bar = NOT (S OR Q)
```

이 식에서 R을 1로 주면 Q는 무조건 0이다. S를 1로 주면 Q_bar가 0이 되고, R이 0인 상태에서 Q는 1이 된다. 두 입력이 0으로 돌아간 뒤에는 두 출력이 서로를 유지한다. 전원이 계속 공급되는 상황을 가정한 설명이다.

## 둘 다 켰다가 끄면

여기까지는 출력이 항상 반대로 나온다. 그런데 S와 R을 둘 다 1로 주면 두 NOR 게이트가 모두 0을 출력한다. Q_bar라는 이름이 붙어 있어도 이때는 Q의 반대가 아니다. 그래서 이 조합을 금지 입력으로 다룬다.

위에서 금지 입력을 누르고, 바로 유지로 바꾸면 Q와 Q_bar가 `?`로 표시된다.

실제 회로에서는 두 입력을 동시에 내릴 때 게이트의 전파 지연이나 소자 차이가 결과에 영향을 준다. 브라우저의 이 모델로는 어느 쪽이 먼저 바뀔지 알 수 없다. 그렇다고 항상 0으로 돌려놓으면 Reset이 된 것처럼 보인다. 여기서는 값을 임의로 정하지 않고 `?`를 남겼다.

```javascript
// 금지 입력에서 두 입력을 함께 0으로 내린 경우
if (wasForbidden) q = null;

// 화면에는 미정 상태를 ?로 표시
const show = value => value === null ? '?' : String(value);
```

실제 전압이 `?`가 된다는 뜻은 아니다. 이 모델에서 결과를 정하지 않았다는 표시다. 전압 변화나 준안정성이 얼마나 지속되는지는 계산하지 않는다.

이 상태에서 Set이나 Reset을 주면 다시 값이 정해진다. 금지 입력 뒤에 유지 대신 Set을 바로 누르는 경우도 마찬가지다. 이 경우는 한쪽 입력이 아직 1이라서 결과를 정할 수 있다.

처음 화면의 Q가 0인 것도 별도 가정이다. 시작 전에 Reset을 줬다고 두었다. 실제 회로가 전원을 켜자마자 항상 0으로 시작하는 건 아니다. 회로식과 기본 동작은 [University of Vermont의 래치 강의](https://www.uvm.edu/~cbcafier/cs2210/content/04_logic_gates/latch_and_flip_flop.html)를 참고했다.

## 동작 확인

브라우저에서 아래 순서로 눌러 결과를 확인했다.

```text
Set → 유지                 Q=1, Q_bar=0
Reset → 유지               Q=0, Q_bar=1
금지 입력                  Q=0, Q_bar=0
금지 입력 → 유지           Q=?, Q_bar=?
금지 입력 → 유지 → Set     Q=1, Q_bar=0
금지 입력 → Reset → 유지   Q=0, Q_bar=1
```

키보드로 버튼을 눌러도 같은 동작이 나오고, 최근 입력 기록은 여섯 개까지만 남긴다. 초기화 가정과 금지 입력 뒤의 상태를 구분하는 데까지 확인한 모델이다.
