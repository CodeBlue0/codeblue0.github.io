## 금융보안원은 어떤 곳인가

금융보안원은 영리기업이 아니라 전자금융거래법에 근거한 **비영리 사단법인**입니다.
2015년 금융보안연구원, 금융결제원 금융ISAC, 코스콤 증권ISAC이 통합해 출범했습니다.

한 금융회사가 혼자 막기 어려운 사이버 위협을 **금융권 전체 단위로 탐지·분석·검증·전파**하는 공동 보안 인프라라고 이해하면 쉽습니다.

| 사업 영역 | 주요 업무 | 직무 연관도 |
|---|---|---|
| 사이버위협 대응 | 통합보안관제, 침해사고 대응, 악성코드 분석, 위협 인텔리전스 | 높음 |
| 취약점 분석·평가 / 모의해킹 | 전자금융기반시설 취약점 평가, 웹·모바일앱 점검, 실전형 모의해킹, 버그바운티 | 높음 |
| 자율보안·디지털전환 지원 | 클라우드·망분리 완화 대응, AI 안전성 평가 | 중간 |
| 정책·연구·교육 | 금융보안 표준, 침투테스트 수행 가이드라인 | 중간 |

## 직무 내용

공고상 Offensive Security 분야는 두 가지 업무를 함께 수행합니다.

1. **침해대응**: 악성코드 분석, 디지털 포렌식
2. **레드티밍**: 취약점 분석·평가, 모의해킹

공격을 아는 사람이 대응도 잘한다는 관점에서 두 업무를 한 직무로 묶은 것으로 보입니다.

## 최근 방향

- **모의해킹 조직 확대**: 실전형 모의해킹 조직이 커지면서 실무형 인력 수요가 늘었습니다.
- **위협 기반 침투테스트 표준화**: 2026년 8월 MITRE ATT&CK과 사이버 킬체인을 기반으로 한 금융분야 침투테스트 수행 가이드라인이 나왔습니다.
- **클라우드 평가 항목 신설**: IAM 설정 오류, 스토리지 노출, 메타데이터 SSRF 같은 클라우드 공격 지식이 필요해졌습니다.
- **AI 보안**: AI 서비스, 에이전트, API가 새로운 공격면이 되었습니다.

## 전형에서 보는 역량

| 단계 | 내용 |
|---|---|
| 이론검증 | 객관식. 네트워크 보안, 시스템 보안, 어플리케이션 보안, 침해사고 대응·분석 |
| 실기 | 모의해킹 및 악성코드 분석 실습 |
| 1차 면접 | 본인이 작성한 실기 답안을 바탕으로 한 심층 면접 |
| 2차 면접 | 조직적합성 |

실기 답안이 면접 질문지가 되므로, 문제를 푸는 것뿐 아니라 **풀이 과정을 논리적으로 설명하는 능력**이 중요합니다.

## 준비 계획

| 영역 | 할 일 |
|---|---|
| 이론 | 4개 과목 핵심 개념 정리와 자가 점검 문제 풀이 |
| 모의해킹 | 웹 → 시스템 → Active Directory 순서로 실습 (CPTS 경로) |
| 악성코드 분석 | PE 구조, 정적 분석(IDA/Ghidra), 동적 분석(샌드박스, 행위 분석) |
| 보고서 | 발견 → 영향 → 재현 → 대응 순서로 쓰는 연습 |

이 과정은 이 블로그에 계속 기록하겠습니다.
