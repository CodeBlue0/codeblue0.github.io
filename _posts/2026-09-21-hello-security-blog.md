금융권 모의해킹 컨설턴트를 목표로 공부한 내용을 기록하려고 블로그를 시작합니다.

## 왜 쓰는가

1. 배운 것을 남에게 설명할 수 있어야 제대로 아는 것이라고 생각합니다.
2. 실기 시험과 면접에서 "무엇을 어떻게 풀었는지" 설명할 근거를 남기고 싶습니다.
3. 모의해킹 업무의 결과물은 결국 보고서입니다. 글쓰기 자체가 연습입니다.

## 무엇을 쓰는가

| 카테고리 | 내용 |
|---|---|
| Roadmap | 목표, 학습 계획, 회고 |
| CTF | Dreamhack, HackTheBox 등 풀이 (종료되거나 Retired된 문제만) |
| CVE | 실제 취약점의 원인 분석, 재현, 탐지 방법 |
| Study | 네트워크·시스템·애플리케이션 보안, 침해사고 대응, 악성코드 분석 |
| Career | 자격증, 채용 전형 준비 |

## 학습 순서

```text
기초   네트워크, 리눅스/윈도우, 웹 동작 원리, Python
 ↓
공격   웹 해킹 → 시스템 해킹 → Active Directory → 피보팅 (HTB CPTS 경로)
 ↓
분석   악성코드 정적/동적 분석, 침해사고 대응, 로그 분석
 ↓
실무   MITRE ATT&CK 기반 시나리오, 보고서 작성
```

## 원칙

- 모든 실습은 허가된 환경(워게임, CTF, 개인 실습 랩)에서만 합니다.
- 진행 중인 대회나 Active 머신의 풀이는 공개하지 않습니다.
- 공격 기법을 쓸 때는 가능하면 탐지와 대응 방법도 함께 씁니다.
